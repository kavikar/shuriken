Mobile smoke prompt for Brand One app using appium-mcp.

- Verify home is visible
- Navigate to order entry
- Capture evidence screenshots

Steps:
1. Start session on Android using configured capabilities.
2. Capture screenshot after launch.

5. Capture screenshot at order entry checkpoint.
